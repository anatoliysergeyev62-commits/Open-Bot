# Universal-AI-Telegram-Base

Асинхронный каркас для Telegram-бота со встроенной интеграцией искусственного интеллекта. Позволяет развернуть бота с памятью диалога, обработкой медиафайлов и гибкой настройкой поведения ИИ.

## 🔥 Функционал
* **Мультимодальность**: Поддержка обработки текста и изображений.
* **Память контекста**: Сохранение истории диалога для каждого пользователя.
* **Кастомизация**: Поддержка системных промптов (инструкций) для смены роли ИИ.
* **Хранение данных**: Логирование пользователей и настроек в базу SQLite.
* **Интерфейс**: Управление через интерактивные инлайн-кнопки.

## 🛠 Стек
* Python 3.10+
* Aiogram 3.x (Асинхронный Telegram API)
* База данных SQLite

## ⚠️ Важное примечание / Disclaimer
Данный код предоставлен "как есть" (as is). На текущий момент проект **не тестировался** в реальной среде, и у автора **нет возможности проверить и отладить его в ближайшее время**. Код может содержать ошибки или требовать доработки перед запуском.
