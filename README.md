# 🤖 Open-Bot — Универсальный AI-ассистент в Telegram

&gt; **Асинхронный Telegram-бот на aiogram 3** с интеграцией Google Gemini API.
&gt; Готовый каркас для создания персонального AI-ассистента с памятью, 
&gt; поддержкой изображений и гибкой настройкой поведения.

---

## ✨ Возможности

| Фича | Описание |
|------|----------|
| 💬 **Память диалога** | Контекст сохраняется в SQLite — бот помнит о чём говорили |
| 🖼️ **Анализ изображений** | Отправь фото — Gemini опишет или проанализирует |
| 🎭 **Системные промпты** | Меняй роль ИИ: программист, переводчик, наставник |
| 📊 **База пользователей** | SQLite-хранилище настроек и истории |
| ⌨️ **Inline-меню** | Управление через кнопки прямо в чате |
| ⚡ **Асинхронность** | aiogram 3 — быстро и без блокировок |
